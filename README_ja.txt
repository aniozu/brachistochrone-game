内容:
  index.html    日本語版

修正点:
1. NORMALの「答えを表示」は次のトライまたはリプレイを開始するときに反映されます。
   描画中は表示せず、チェック操作だけでも正解は出ません。
   レース途中にチェックを切り替えても現在のレースには影響しません。
2. スコア表示画面では、チェックの状態にかかわらず黄色い最速降下曲線・球を非表示にします。
   以前に答えを表示して競争したレースのあとでも、結果画面では正解を表示しません。
3. タイトル画面のボタン以外の場所では、マウスが手形にならないように修正。
4. 週間・全期間ランキングとGoogle Apps ScriptのURLは前版と同じです。
5. 表示バージョンはv0.2 betaのままです。

注意: ランキング登録は本番のGoogleスプレッドシートに送信されます。
GitHub Pagesで更新するときは、2つのHTMLをそれぞれ上書きしてください。
